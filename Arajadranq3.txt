Հարց 1։ Ինչ է անում flex-wrap-ը։

Պատասխան։ `flex-wrap`-ը CSS-ի հատկություն է, որը որոշում է՝ flex կոնտեյների ներսի տարրերը կարո՞ղ են անցնել նոր տող, երբ տեղը չի բավականացնում։

**Արժեքները**

- `nowrap` (լռելյայն). բոլոր տարրերը մնում են մեկ տողում։ Եթե տեղը չի հերիքում, տարրերը փոքրանում են (`flex-shrink`-ի շնորհիվ) կամ դուրս են գալիս կոնտեյների սահմաններից։
- `wrap`. երբ տարրերը չեն տեղավորվում, նրանք անցնում են հաջորդ տող՝ վերևից ներքև։
- `wrap-reverse`. նույնը, ինչ `wrap`-ը, բայց նոր տողերը ավելանում են վերևում, այսինքն՝ տողերի հերթականությունը հակադարձվում է։

**Օրինակ**

```css
.container {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}

.item {
  width: 200px;
}
```

Եթե կոնտեյների լայնությունը, ասենք, 500px է, ապա մեկ տողում կտեղավորվեն 2 տարր, մնացածը կանցնեն հաջորդ տողերին։ `nowrap`-ի դեպքում 200px լայնությամբ տարրերը կսեղմվեին մեկ տողում։

**Կարևոր է իմանալ**

- Հատկությունը կիրառվում է **կոնտեյների** վրա, ոչ թե առանձին տարրերի։
- Այն հաճախ գրվում է կրճատ ձևով՝ `flex-flow: row wrap;` (սա `flex-direction`-ի և `flex-wrap`-ի համադրությունն է)։
- Երբ տարրերը բաժանվում են մի քանի տողի, `align-content`-ը որոշում է, թե այդ տողերն ինչպես բաշխվեն ուղղահայաց առանցքով, իսկ `justify-content`-ը գործում է յուրաքանչյուր տողի ներսում։
- Սա շատ օգտակար է ռեսպոնսիվ դիզայնի համար, օրինակ՝ քարտերի ցանցի համար, որտեղ էկրանի լայնությանը համապատասխան քարտերի քանակը տողում փոխվում է ինքնաբերաբար։


Արդյունք։ Տեքստը ճիշտ է և համապատասխանում է MDN-ին։


Հարց 2։ Որն է <section>-ի և <div>-ի տարբերությունը։

Պատասխան։ `<div>`-ը և `<section>`-ը երկուսն էլ բլոկային կոնտեյներներ են, բայց տարբերությունը իմաստի (սեմանտիկայի) մեջ է։

**`<div>`**
- Ընդհանուր նշանակության կոնտեյներ է, որը **ոչ մի իմաստ չունի**։
- Օգտագործվում է, երբ տարրերը պետք է խմբավորել միայն ոճավորման (CSS) կամ JavaScript-ի համար, օրինակ՝ layout-ի, flex/grid կոնտեյների համար։

**`<section>`**
- **Սեմանտիկ** տարր է (HTML5)․ նշանակում է, որ բովանդակությունը թեմատիկ առումով առանձին բաժին է։
- Սովորաբար ունի վերնագիր (`<h2>`, `<h3>` և այլն)։
- Օգնում է էկրանի ընթերցիչներին և որոնողական համակարգերին հասկանալ էջի կառուցվածքը։

**Օրինակ**

```html
<!-- section. թեմատիկ բաժին՝ վերնագրով -->
<section>
  <h2>Մեր ծառայությունները</h2>
  <p>...</p>
</section>

<!-- div. պարզապես խմբավորում ոճավորման համար -->
<div class="cards-grid">
  <div class="card">...</div>
  <div class="card">...</div>
</div>
```

**Ինչպես ընտրել**

- Եթե բովանդակությունը կարող է ունենալ իր սեփական վերնագիրը և կազմում է էջի առանձին թեմատիկ մասը, օգտագործեք `<section>`։
- Եթե խմբավորումը զուտ տեխնիկական է (layout, wrapper, ոճավորում), օգտագործեք `<div>`։
- Եթե կա ավելի կոնկրետ սեմանտիկ տարր (`<article>`, `<nav>`, `<header>`, `<footer>`, `<aside>`, `<main>`), նախընտրեք այն։

Պարզ կանոն. եթե հարցնում եք «սա էջի առանձին բաժի՞ն է վերնագրով», ապա `<section>`, եթե ոչ՝ `<div>`։ Բրաուզերը երկուսին էլ ցուցադրում է նույն կերպ, տարբերությունը հասանելիության, SEO-ի և կոդի ընթեռնելիության մեջ է։


Արդյունք։ Տեքստը ճիշտ է և համապատասխանում է MDN-ին։


Հարց 3։ Ինչ է անում flex-direction-ը։ 

Պատասխան։ `flex-direction`-ը CSS-ի հատկություն է, որը որոշում է flex կոնտեյների **հիմնական առանցքի (main axis)** ուղղությունը, այսինքն՝ ո՞ր ուղղությամբ են շարվում տարրերը։

**Արժեքները**

- `row` (լռելյայն). տարրերը շարվում են հորիզոնական՝ ձախից աջ։
- `row-reverse`. հորիզոնական, բայց աջից ձախ։
- `column`. տարրերը շարվում են ուղղահայաց՝ վերևից ներքև։
- `column-reverse`. ուղղահայաց, բայց ներքևից վերև։

**Օրինակ**

```css
.container {
  display: flex;
  flex-direction: column;
  gap: 10px;
}
```

Այստեղ տարրերը կշարվեն իրար տակ, ոչ թե կողք կողքի։

**Կարևոր է իմանալ**

- Հատկությունը կիրառվում է **կոնտեյների** վրա։
- Այն փոխում է նաև առանցքների դերերը. երբ `flex-direction: column` է, հիմնական առանցքը դառնում է ուղղահայաց, ուստի `justify-content`-ը սկսում է աշխատել ուղղահայաց, իսկ `align-items`-ը՝ հորիզոնական։
- `-reverse` արժեքները փոխում են միայն տարրերի **տեսողական** հերթականությունը, բայց ոչ DOM-ի։ Դա կարող է խանգարել ստեղնաշարով նավիգացիային և էկրանի ընթերցիչներին, ուստի զգույշ օգտագործեք։
- Կրճատ ձևով կարելի է գրել `flex-flow: column wrap;` (`flex-direction` + `flex-wrap`)։

Արդյունք։ Տեքստը ճիշտ է և համապատասխանում է MDN-ին։
